# AI Usage Disclosure

AI-assisted development tools were used to support implementation, debugging,
testing, architecture review, documentation, and research across the project.

Specifically, we used:

- Codex-backed tooling for rapid code generation, refactoring, debugging support,
  system design iteration, and validation assistance.
- Claude for frontend-focused design and implementation support, including
  component iteration, UI refinement, styling guidance, and front-end logic
  assistance.

These tools were used as accelerators for engineering work, not as autonomous
sources of authority. All generated code, design suggestions, and technical
recommendations were reviewed, validated, and understood by the team before
being incorporated into the final implementation.

AI agents are advisory and do not hold authority over RecallGuard recovery
decisions.

Deterministic validation policies decide whether repaired data is safe to
return to the GapRadar intelligence pipeline.
