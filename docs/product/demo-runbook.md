# GapRadar Demo Runbook

This runbook is a practical sequence for a 2-4 minute product demo.

## Recommended Order

1. Discovery dashboard
2. Open a top opportunity
3. Show opportunity research context
4. Reliability / RecallGuard view
5. Investigation create + run
6. Investigation evidence tabs (research, demand, competitors)
7. MCP or CLI (optional if time permits)

## Suggested Narrative

### 1) Discovery dashboard

Message:

- GapRadar is not a raw scraping output viewer.
- It converts trusted web signals into ranked opportunities.

### 2) Opportunity detail

Message:

- Each opportunity has source context and a transparent score breakdown.
- The goal is traceable opportunity intelligence.

### 3) Reliability view

Message:

- Reliability is a product feature, not hidden infrastructure.
- GapRadar can detect extraction drift and prevent unreliable data from influencing decisions.

### 4) Investigation mode

Message:

- Users can submit their own idea and ask GapRadar to investigate it.
- Investigation execution is explicit (user-triggered), not silently run on read.

### 5) Investigation evidence

Message:

- Research evidence: technical feasibility signals.
- Demand evidence: public-web pain and search intent signals.
- Competitors: direct/adjacent/substitute candidate landscape.

## Claims to Keep Precise

- Say "evidence-backed" and "trust-gated".
- Avoid claiming guaranteed business outcomes.
- Avoid claiming full autonomous self-healing in production unless you show explicit proof for that scenario.
